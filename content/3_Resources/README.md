# 3. Resources (자원)

지금 당장 실행하거나 해결해야 하는 일은 아니지만, 관심이 있어서 모아두는 지식, 레퍼런스, 정보 등을 기록하는 폴더입니다.

## 특징
- **비행동성**: 당장 마감일이 없으며, 미래의 나에게 도움이 될 만한 가벼운 관심사 위주로 구성됩니다.
- **백과사전**: 나만의 위키백과를 만드는 느낌으로 정리하면 좋습니다.

## 예시
- `CSS/JS 코딩 공부 레퍼런스`
- `가보고 싶은 전국의 맛집/카페 리스트`
- `독서 기록 및 좋은 문장 아카이브`
- `여행 가고 싶은 국가 정보`
- `좋아하는 디자인 영감 스크랩`

# 99. System (시스템)

옵시디안의 원활한 작동을 도와주는 설정 파일, 양식(템플릿), 첨부파일 등이 저장되는 폴더입니다.

## 내부 폴더 구성
- **`Attachments/`**: 노트에 드래그 앤 드롭으로 넣은 이미지, PDF, 오디오 등의 원본 파일이 자동으로 저장되는 폴더입니다.
- **`Templates/`**: 반복되는 작성 양식(일기 형식, 프로젝트 관리 템플릿 등)을 관리하는 곳입니다.

## 추천 설정 방법 (첨부파일)
1. 옵시디안 설정(`Ctrl + ,`)을 엽니다.
2. `파일 및 링크` 메뉴로 이동합니다.
3. `새 첨부파일 저장 경로`를 **"아래에 지정된 폴더"**로 설정합니다.
4. 그 아래 폴더 지정 칸에서 **`99_System/Attachments`**를 선택합니다.

# 4. Archives (보관소)

완료된 프로젝트나 더 이상 관리하지 않는 영역, 자원들을 보관하는 폴더입니다.

## 특징
- **과거의 기록**: 지우기는 아깝지만 현재 나에게 즉시 필요하지 않은 죽은 노트를 모아두는 곳입니다.
- **노트의 무덤 & 저장소**: 현재 시점의 사이드바를 깨끗하게 유지하기 위해 주기적으로 정리하여 이곳으로 보냅니다.
- **검색 가능**: 폴더 깊숙이 보관되어 있어도 옵시디안의 전체 검색(`Ctrl + Shift + F`)을 통해 언제든 꺼내볼 수 있습니다.

## 예시
- `2025년 이사 프로젝트` (완료됨)
- `과거에 다니던 회사의 업무 폴더` (퇴사함)
- `한때 빠졌던 취미 관련 자원` (비활성화됨)

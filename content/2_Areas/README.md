# 2. Areas (영역)

기한(데드라인)은 없지만, 내가 살아가는 동안 지속적으로 유지하고 관리해야 하는 책임 영역들을 기록하는 폴더입니다.

## 특징
- **지속성**: 프로젝트처럼 '완료'라는 개념이 없습니다. 지속적으로 점검하고 가꾸어야 하는 삶의 테마들입니다.
- **기준점**: 내 삶의 기준과 가치가 투영되는 곳입니다.

## 예시
- `건강 관리` (식단, 운동 루틴, 병원 기록 등)
- `재테크` (자산 포트폴리오, 가계부 피드백 등)
- `가족 & 인간관계` (가족 행사 계획, 친구 연락처 등)
- `회사 업무` (직무 매뉴얼, 연간 성과 정리 등)
- `자기계발` (독서 습관, 일기 등)
